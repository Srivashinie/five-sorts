# Five Sorts

A daily five-letter word-guessing game in a single HTML file. Six tries, with print-shop ink hints:

- **Blue (locked):** right letter, right spot
- **Pink (loose):** in the word, wrong spot
- **Grey (dead):** not in the word

Includes a daily word, practice mode, hard mode, streak stats and shareable results.

Play it: https://srivashinie.github.io/five-sorts/
